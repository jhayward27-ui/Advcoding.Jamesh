# RISE Skill Lab

A training guide website for athletes who want to get better. Each sport breaks down into **four major skills**, with:

- Why the skill matters
- Step-by-step improvement advice
- A simple weekly plan
- An embedded training video

## Sports covered

- Hockey
- Baseball
- Soccer
- Football
- Lacrosse
- Golf
- Basketball

## Run locally

```bash
npm install
npm run dev -- --port 43123
```

Open [http://127.0.0.1:43123](http://127.0.0.1:43123).

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- shadcn/ui
